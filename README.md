# Capstone2025
This repository holds my project capstone for my Data Science Degree
Comparative Analysis of Machine Learning Models for Housing Price Index Prediction
This project leverages machine learning techniques to predict the U.S. Housing Price Index (HPI) across different regions and time periods using data from the Federal Housing Finance Agency (FHFA). It includes comprehensive exploratory data analysis to understand temporal and geographic trends in housing prices, followed by the implementation and evaluation of various regression models-from linear regressors to advanced ensemble methods like LightGBM and Random Forest.

Key features such as year, location, and index type are used to train models, with LightGBM achieving the best performance (R² ≈ 0.997, MSE ≈ 0.000031). The project also includes hyperparameter tuning and feature importance analysis to improve accuracy and interpretability.

This repository contains the full data preprocessing pipeline, modeling code, evaluation metrics, and visualization scripts, providing a robust framework for housing market forecasting and economic analysis.

Technologies used: Python, scikit-learn, LightGBM, XGBoost, pandas, seaborn, matplotlib.

Data source: Federal Housing Finance Agency (FHFA) House Price Index datasets.
